3 минуты японской Radio Taiso = час работы агента. Для тех, кто сидит с Claude Code по 10 часов и чья спина уже всё поняла.

Установка — одна команда в Терминале
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/weinsteinsasha/taiso/main/get.sh)"

macOS · Claude Code · Homebrew · Xcode CLT. Код открыт: github.com/weinsteinsasha/taiso

01
Работаешь как обычно Баланс минут — в menubar (⛩ 58) и в конце каждого ответа Клода. Пока агент пашет, счётчик честно тает.
02
Кончился баланс — можно в долг До −20 минут: звонок или поток никто не рубит. Но долг удорожает зарядку в полтора раза.
03
Долг исчерпан — Клод останавливается И сам, своими словами, уговаривает тебя встать. Экран, браузер, звонки работают. Не работает только агент.
04
3 минуты Radio Taiso — и дальше Полноэкранное видео, встал у стола, повторил, окно само закрылось. Стрик растёт, спина отпускает.
«Напоминания от Гармина не работают никогда. Спина болит по утрам, пока не разомну» — каждый опрошенный оператор агентов, 8–12 часов в день. Добровольные напоминалки закрываются одной кнопкой. Работает только шлагбаум.
Никакой камеры · никаких серверов · ноль сетевых вызовов в рантайме · всё локально
