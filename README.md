# ⛩ Radio Taiso

**Claude Code refuses to work until you've done your 3-minute Japanese calisthenics. Your agent finally cares about your body.**

Клод не будет работать, пока ты не сделаешь зарядку. 3 минуты японской Radio Taiso = час работы агента.

## Проблема

Код теперь пишет агент, а ты сидишь и смотришь. Усталость, которая раньше поднимала тебя из-за стола, исчезла: операторы агентов сидят по 8–12 часов подряд, ничего с этим не делают — и у всех болит спина. Напоминания не работают ни у кого (даже платный Garmin). Работает только одно: когда следующая итерация с агентом физически недоступна, пока не подвигаешься.

## Как это работает

1. **Работаешь как обычно.** Каждая зарядка покупает время работы агента (по умолчанию 60 минут). Баланс — в menubar (⛩ 58) и в конце каждого ответа Клода.
2. **Баланс кончился — можно в долг** до −20 минут (звонок, поток). Долг удорожает следующую зарядку в полтора раза.
3. **Долг исчерпан — Клод останавливается.** Не молча: он сам, своими словами, предлагает встать и размяться. Инструменты заблокированы, экран, браузер и звонки — нет.
4. **`taiso go`** — полноэкранное видео Radio Taiso (~3:22). Свернул — пауза, честный досмотр. Досмотрел — работа продолжается.

Никакой камеры, никаких серверов, ноль сетевых вызовов в рантайме. Всё локально. Обмануть можно — но система это запишет, а врать самому себе ты и без неё умеешь.

## Установка (macOS + Claude Code)

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/weinsteinsasha/taiso/main/get.sh)"
```

Что произойдёт: скачается видео (1080p, ~65 МБ), в `~/.claude/settings.json` добавятся hooks (с таймстампованным бэкапом; существующие hooks не трогаются байт-в-байт), запустится menubar, четыре вопроса анкеты настроят твой ритм.

Требования: macOS, [Claude Code](https://claude.com/claude-code), Homebrew, Xcode Command Line Tools.

## Управление

Словами в Claude Code: «баланс?», «давай зарядку», «стрик?» — или CLI: `taiso status | go | stats`. Настройки: клик по ⛩ в menubar → Интервал, или `~/.radio-taiso/config.json`.

## Снятие

```bash
~/.radio-taiso/bin/uninstall.sh
```

Хирургически убирает только свои записи из settings.json, статистику по умолчанию оставляет.

## Как устроено

Python-ядро (stdlib, SQLite WAL) + Swift-окно/menubar + bash-установщик. Блокировка — на границе хода через UserPromptSubmit/PreToolUse hooks: начатая работа агента всегда доделывается. Fail-open: любая ошибка инструмента — работа НЕ блокируется. Allowlist разблокировки парсится, а не матчится регэкспом — `taiso go; rm -rf ~` не пройдёт.
